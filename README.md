[𝗏𝐞𝗋𝗌𝐢𝐨𝗇𝐞𝖽 𝖿𝐨𝗋𝗆𝐚𝗍𝗌](specs/hexmoji-formats.md) 𝖼𝐨𝗇𝗍𝐚𝐢𝗇𝗌 𝗍𝗁𝐞 𝖿𝐮𝗅𝗅 𝗐𝐢𝗋𝐞 𝗋𝐮𝗅𝐞𝗌. [𝗉𝗋𝐨𝗏𝐞𝗇𝐚𝗇𝖼𝐞](PROVENANCE.md) 𝗋𝐞𝖼𝐨𝗋𝖽𝗌 𝗅𝐢𝗅𝗒’𝗌 𝗍𝐞𝐚𝖼𝗁𝐢𝗇𝗀 𝐞𝗑𝐚𝗆𝗉𝗅𝐞𝗌, 𝗍𝗁𝐞 𝗋𝐞𝖼𝐨𝗏𝐞𝗋𝐞𝖽 𝗍𝐚𝖻𝗅𝐞𝗌 𝐚𝗇𝖽 𝗍𝗁𝐞 𝗏2 𝐞𝗑𝗍𝐞𝗇𝗌𝐢𝐨𝗇. 𝗍𝗁𝐞 𝐨𝗋𝐢𝗀𝐢𝗇𝐚𝗅 𝗌𝐮𝐢𝗍𝐞 𝗌𝐨𝐮𝗋𝖼𝐞 𝗋𝐞𝗆𝐚𝐢𝗇𝗌 𝐮𝗇𝖼𝗁𝐚𝗇𝗀𝐞𝖽 𝐢𝗇 `archive/recovered/`.

## 𝗁𝐚𝗇𝖽𝗌 𝐢𝗇 𝗍𝗁𝐞 𝗀𝐚𝗋𝖽𝐞𝗇

𝗌𝗉𝐞𝖼𝐢𝖿𝐢𝖼𝐚𝗍𝐢𝐨𝗇𝗌, 𝗅𝐨𝗀𝐢𝖼 𝐚𝗇𝖽 𝐞𝗑𝗉𝐞𝗋𝐢𝗆𝐞𝗇𝗍𝗌: 𝗅𝐢𝗅𝗒 𝐨𝖿 𝐚𝗌𝗁𝗐𝐨𝐨𝖽. 𝖼𝐨𝖽𝐞 𝐚𝗇𝖽 𝖽𝐞𝗌𝐢𝗀𝗇 𝖽𝐞𝗏𝐞𝗅𝐨𝗉𝐞𝖽 𝗐𝐢𝗍𝗁 𝐚𝐢 𝐚𝗌𝗌𝐢𝗌𝗍𝐚𝗇𝖼𝐞, 𝐢𝗇𝖼𝗅𝐮𝖽𝐢𝗇𝗀 𝖼𝗅𝐚𝐮𝖽𝐞’𝗌 𝐞𝐚𝗋𝗅𝐢𝐞𝗋 𝐢𝗆𝗉𝗅𝐞𝗆𝐞𝗇𝗍𝐚𝗍𝐢𝐨𝗇 𝐚𝗇𝖽 𝖼𝐨𝖽𝐞𝗑’𝗌 2026 𝖼𝐨𝗇𝗍𝐢𝗇𝐮𝐚𝗍𝐢𝐨𝗇. 𝗍𝗁𝐞 𝖼𝐨𝗇𝗍𝐢𝗇𝐮𝐚𝗍𝐢𝐨𝗇 𝐚𝖽𝖽𝗌 𝗏𝐚𝗅𝐢𝖽𝐚𝗍𝐢𝐨𝗇, 𝗍𝗁𝐞 𝗏𝐞𝗋𝗌𝐢𝐨𝗇𝐞𝖽 𝖻𝗒𝗍𝐞 𝗆𝐨𝖽𝐞, 𝐨𝖿𝖿𝗅𝐢𝗇𝐞 𝗐𝐨𝗋𝗄𝗌𝗁𝐨𝗉, 𝖼𝗅𝐢 𝐚𝗇𝖽 𝗍𝐞𝗌𝗍𝗌.
